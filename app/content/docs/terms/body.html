The gateway is not a guarantee

Rules, approvals, and tool pins reduce risk. They do not remove it. A rule can be set up wrong, a call can be allowed that you meant to block, and an approval message or phone call can be late or never arrive. The gateway does not stop prompt injection: a tool result can still tell an AI agent to do something you did not intend.

Do not let an agent take an action through Fizzlayer that you could not afford to have go wrong. Keep backups, use the narrowest credentials that work, and require approval for anything that moves money, deletes data, or reaches other people.
