Gateway · available once deployed

Point an MCP client at your hosted gateway.

Creating a shared gateway stores https://gw.fizzlayer.com/w/<gateway-id>/mcp. That URL answers after the shared fleet is deployed. It is not live yet.

Hobbyist and Tinkerer each include one shared gateway. The client sends Authorization: Bearer with a token minted for that gateway. The token's audience is the gateway URL, so a token for one gateway is rejected on another. Remote HTTP and SSE servers only; stdio stays on a Pro dedicated gateway.

Upstream API keys stay on the server. The signed-in config preview does not include them. Tool calls are counted per gateway for later metering. Audit rows are kept 7 days on Hobbyist, 30 on Tinkerer, and 90 on Pro.

Self-hosting the data plane is described in the repository under gateway/README.md. Sensors stay at Sensors docs.
