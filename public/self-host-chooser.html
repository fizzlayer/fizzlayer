Sensors, available now

Docker Compose for the website, API, worker, readings, WebSocket, and MQTT. Install the sensors stack.

Gateway, from the repository

Docker builds the local image. Docker Hub does not have a fizzlayer/fizzlayer-gateway tag yet, and fizzlayer.com does not host a gateway. Clone the repo and run gateway/compose/test.sh for standalone mode, or gateway/compose/test-linked.sh for fizz-agent. Steps are in the gateway docs. Join the hosted list if you want a URL later.
