# Server logos

The "Works with" marks on the home page. Each file is one shape from
[Simple Icons](https://simpleicons.org) 16.38.1 (npm package `simple-icons`),
released under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
None of these icons has its own licence entry in the Simple Icons data. The only
changes are a single fill colour (`#3d5266`, the site's body text) and dropping
`role="img"`.

| File | Brand | Brand guidelines, or the icon's source where Simple Icons lists none |
| --- | --- | --- |
| `github.svg` | GitHub | https://github.com/logos |
| `stripe.svg` | Stripe | https://stripe.com/newsroom/information (source) |
| `postman.svg` | Postman | https://www.getpostman.com/resources/media-assets/ (source) |
| `cloudflare.svg` | Cloudflare | https://www.cloudflare.com/trademark/ |
| `neon.svg` | Neon | https://neon.com/brand |
| `posthog.svg` | PostHog | https://posthog.com/handbook/company/brand-assets |
| `huggingface.svg` | Hugging Face | https://huggingface.co/brand |

The logos are trademarks of their owners. They mark servers in the app's
catalog (`app/src/catalog.gleam`) that a gateway can connect to. They do not
mean the owner endorses Fizzlayer. Add a logo only for a server in that catalog,
and check the brand's guidelines first.
