HOME ASSISTANT

Connect Home Assistant

Bring temperature, humidity, power, door, and leak sensors from a Home Assistant install into this workspace. Home Assistant pushes readings out, so the install can stay off the public internet. Each entity you share counts toward your plan's device limit.

  1. Install via HACS

    Home Assistant needs the Fizzlayer integration before it can be added. Without it, Add integration shows "This integration does not support configuration via the UI." This opens HACS, or the Marketplace on Home Assistant 2026.11 and newer, and adds this repository as an Integration.

    Restart Home Assistant after the install finishes. The next step does not work until you do.

  2. Add the integration

    After the restart, add Fizzlayer. The first time, My Home Assistant asks you to confirm your instance URL. Home Assistant shows a 6-digit code and opens the Fizzlayer Allow page. Sign in if you need to. The page names this install and its version. Type the code from the Home Assistant screen, then choose Allow. A code from a message is not enough, and you never copy a device token. Then pick the entities to share. Temperature, humidity, power, door, and leak sensors start selected.

Install without HACS

Clone the repository and copy custom_components/fizzlayer into your Home Assistant config's custom_components folder. /config is that folder's parent on Home Assistant OS, Supervised, and the official container. Restart, then use Add integration above.

git clone --depth 1 https://github.com/fizzlayer/fizzlayer.git
mkdir -p /config/custom_components
cp -a fizzlayer/custom_components/fizzlayer /config/custom_components/

Home Assistant in Docker, with the container named homeassistant:

git clone --depth 1 https://github.com/fizzlayer/fizzlayer.git
docker exec homeassistant mkdir -p /config/custom_components
docker cp fizzlayer/custom_components/fizzlayer homeassistant:/config/custom_components/fizzlayer
docker restart homeassistant

If your config directory is not /config, copy the folder into that directory's custom_components instead. Add integration shows a 6-digit code and opens the Fizzlayer Allow page for fizzlayer.com, including when Advanced Mode is on. The screen also shows the integration version.

    Where the code is shown

    Home Assistant shows a 6-digit code on its own screen and opens the Fizzlayer Allow page. Type the code from that Home Assistant screen, then choose Allow. A code from a message is not accepted. The screen also shows the integration version.

      03 / OPEN API

      Send your own data

      Add a sensor as a real device, or switch a sample sensor to API mode. Fizzlayer shows its key once, then accepts JSON readings over HTTPS. Each sensor has its own key so you can rotate or revoke it independently. Copy the sensor_id from its card above.

      curl -X POST https://fizzlayer.com/api/ingest \
  -H 'Authorization: Bearer YOUR_SENSOR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"sensor_id":"YOUR_SENSOR_ID","event_id":"sample-001","metrics":{"temperature_c":27.4}}'
