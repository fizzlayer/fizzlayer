ABOUT FIVE MINUTES AFTER YOU SIGN IN

Send one real reading with curl

Sign in to create the sensor and copy its key. Create an account or sign in. A new account has to confirm its email first.

This stores a reading on a real sensor. It is not a sample stream. Sample streams are simulated and labeled Simulated. Phone motion needs a separate permission, and Home Assistant needs an install and a restart, so this curl is the shortest path that works today.

  1. Add a Temperature sensor as a real device. In Add a sensor below, choose Temperature and Real device, not Sample stream. Copy the API key when it is shown. It is shown once. Copy the sensor ID from the card.
  2. Post one reading. Replace the two placeholders and run this from a terminal. A 202 means it was stored. The sensor card and the dashboard show it.
curl -X POST https://fizzlayer.com/api/ingest \
  -H 'Authorization: Bearer YOUR_SENSOR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"sensor_id":"YOUR_SENSOR_ID","event_id":"first-reading","metrics":{"temperature_c":21.5}}'

Phone-call alerts are on Tinkerer, Pro, and Enterprise. Hobbyist gets dashboard alerts and MCP.

WHAT THE SENSOR TYPES ACCEPT

Water, temperature, and gas

Water flow and leaks

A Water sensor accepts flow_l_min from 0 to 200 and a true or false leak flag. A threshold shows on the dashboard when a reading crosses the limit you set.

Fizzlayer is not a safety system. Never rely on it alone to protect people or property.

Temperature, including a cold room

A Temperature sensor accepts temperature_c from −100 to 200. The same sensor can watch a server closet or a cold room. The alert appears on the dashboard.

Fizzlayer is not a safety system. Never rely on it alone to protect people or property.

Gas concentration

A Gas sensor accepts concentration_ppm from 0 to 10,000 and a true or false alarm flag. It stores those readings beside a detector you already have. It does not replace that detector.

Fizzlayer is not a safety system. Never rely on it alone to protect people or property.

Phone-call alerts for these are on Tinkerer, Pro, and Enterprise. Hobbyist gets dashboard alerts and MCP.

    Submit the code here, then return to the device terminal. Check the account name and approve the request to finish connecting. You can also ask a connected agent to claim the code.

  4. Start sending readings

    After approval, run this on your device to stream CPU temperature, load, memory, and disk usage where available:

    Your device appears as a Custom sensor on the Sensors page. Keep the command running to send a reading every minute. fizz run --stream --every 15 keeps one WebSocket open, fizz send --mqtt publishes MQTT, and fizz tail prints live readings. Those commands read addresses from GET /api/stream. Hosted MQTT is WebSocket only; there is no TCP port 1883.

Using an ESP32 or another microcontroller? Add a sensor below as a Real device to get its own API key. To connect a phone, add a Phone sensor as a Real device to get a link to open on it.

HOME ASSISTANT

Connect Home Assistant

Bring temperature, humidity, power, door, and leak sensors from a Home Assistant install into this workspace. Home Assistant pushes readings out, so the install can stay off the public internet. Each entity you share counts toward your plan's device limit.

Fizzlayer is not a safety system. Never rely on it alone to protect people or property.

  1. Install via HACS

    Home Assistant needs the Fizzlayer integration before it can be added. Without it, Add integration shows "This integration does not support configuration via the UI." This opens HACS, or the Marketplace on Home Assistant 2026.11 and newer, and adds this repository as an Integration.

    Restart Home Assistant after the install finishes. The next step does not work until you do.

  2. Add the integration

    After the restart, add Fizzlayer. The first time, My Home Assistant asks you to confirm your instance URL. The dialog title and the pairing-code field show a 6-digit code. Open the Allow page from the link in that dialog. Sign in if you need to. The page names this install and its version. Type the code from the Home Assistant dialog, then choose Allow. A code from a message is not enough, and you never copy a device token. Then pick the entities to share. Temperature, humidity, power, door, and leak sensors start selected.

Install without HACS

Clone the repository and copy custom_components/fizzlayer into your Home Assistant config's custom_components folder. /config is that folder's parent on Home Assistant OS, Supervised, and the official container. Restart, then use Add integration above.

git clone --depth 1 https://github.com/fizzlayer/fizzlayer.git
mkdir -p /config/custom_components
cp -a fizzlayer/custom_components/fizzlayer /config/custom_components/

Home Assistant in Docker, with the container named homeassistant:

git clone --depth 1 https://github.com/fizzlayer/fizzlayer.git
docker exec homeassistant mkdir -p /config/custom_components
docker cp fizzlayer/custom_components/fizzlayer homeassistant:/config/custom_components/fizzlayer
docker restart homeassistant

If your config directory is not /config, copy the folder into that directory's custom_components instead. Add integration shows a 6-digit code in the dialog title and in the pairing-code field, including when Advanced Mode is on. The link in that dialog opens the Allow page for fizzlayer.com. The screen also shows the integration version.
