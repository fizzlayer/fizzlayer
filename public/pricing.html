Pricing

Hobbyist is free. Tinkerer is $10. Pro is $25.

Those prices cover Sensors, which you can use today, and the gateway counts in the API. The shared call cap is enforced. Gateway and server counts return 402 when you pass them. Monthly tool-call totals are not metered. Sample sensors stay unlimited. Phone-call alerts and phone approvals are on paid plans only. Tinkerer and Pro share one monthly call cap. Tinkerer includes 20 calls a month and Pro includes 100. Enterprise is unlimited unless a contract sets a cap. The cap resets on the first of each month (UTC). Hobbyist ($0) includes dashboard and webhook alerts. Email alerts are included on every plan, including Hobbyist, and the dashboard shows email only when mail is configured. On fizzlayer.com that choice is hidden.

Gateway

These numbers are on fizz_plans. The phone-call column is dialed today and is shared by sensor alerts and phone approvals. A hosted shared gateway is not running, and Pro does not start a dedicated machine. Slack approvals are not available.
